Packages

What each tier
allows.

Every approved account can stream titles already in the library. Higher tiers add a monthly request quota — shows and movies we review and add to the shared library when capacity allows.

Free

Standard

Best if you only want to watch what is already available.

  • Full browse and playback of existing libraries
  • Browser access after Cloudflare Access
  • Optional WARP / Cloudflare One for mobile
  • No media requests — view-only
$10

Donor

Light request quota for occasional new titles.

  • Everything in Free
  • Up to 1 show and 3 movies per month
  • Requests go into the shared library after review
  • Queue time varies with volume
$15

Super Donor

More headroom if you request regularly.

  • Everything in Free
  • Up to 3 shows and 10 movies per month
  • Same review and shared-library model as Donor
  • Queue time varies with volume
$20

Mega Donor

Highest published request quota.

  • Everything in Free
  • Up to 5 shows and 20 movies per month
  • Still subject to review — not unlimited personal downloads
  • Queue time varies with volume

Choose your package on the Access form. How to connect after approval is on Instructions. Stack details (Jellyfin, Access, WARP) are on Services.
