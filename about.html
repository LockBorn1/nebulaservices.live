About

How the project
is run.

Nebula Services runs a closed media library and the access controls around it. Public pages explain the offer; accounts are created only after review.

Scope

We operate a private Jellyfin library protected by Cloudflare Access and optional Cloudflare One (WARP). Content is acquired through legitimate channels. The public site is for information and access requests — not open registration.

Access model

Anyone may submit a request when applications are open. Approval is manual. After approval you receive library credentials by email. Package tiers (Free, Donor, Super, Mega) define request quotas; Free is view-only. Setup steps are on the public Instructions page.

Legal & privacy

Access is for approved individuals only. Credential sharing is grounds for termination. We have methods in place to detect it. Full text: Legal · Privacy.
