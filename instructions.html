Before you start

From your approval email you need: the approved email address, Jellyfin username, and Jellyfin password.

Tip: Use a desktop browser first. Add WARP later for mobile or restricted networks.

Method A — Browser (desktop / laptop)

  1. Open the library URL

    In Chrome, Edge, Firefox, or Safari go to https://jellyfin.nebulaservices.live. Use HTTPS only. Bookmark the hostname after it loads.

  2. Complete Cloudflare Access

    Sign in with the exact email we approved. Enter the one-time code Cloudflare sends. Jellyfin will not load until this succeeds.

    Stuck? Wrong email is the most common issue. It must match the approval letter.
  3. Sign in to Jellyfin

    Use the username and password from the approval email. If approval was only minutes ago and login fails, wait 5–10 minutes and try again.

  4. Playback

    Prefer Direct Play when available. If buffering, lower quality in the player. Report broken titles by email — never post credentials publicly.

Method B — Mobile & Cloudflare One (WARP)

Install

  1. Install official WARP / Cloudflare One

    From the App Store, Play Store, or Cloudflare’s official desktop download only.

Join the organization

  1. Team / organization login

    Enter organization name exactly: nebulaservices

  2. Authenticate

    Use the same approved email. Toggle the connection On and leave it on while streaming.

Open Jellyfin

  1. Browser or app

    With WARP connected, open https://jellyfin.nebulaservices.live, pass Access, then sign in with your library credentials. In the Jellyfin app, add that same server URL.

  2. If it fails

    Confirm WARP is connected to nebulaservices, Access used the approved email, and the password matches the letter. Then email the admin with your device type and which step fails.

Do not share credentials. Sharing is grounds for termination. We have methods in place to detect it. Admin: milnerg-admin@nebulaservices.live
