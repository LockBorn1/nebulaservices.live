Before you start

Have your approval email open. You will need three things from it.

  1. Confirm you have approval

    You should have an email with your approved address, Jellyfin username, and Jellyfin password. If you do not, wait for review or check spam.

  2. Use the exact approved email

    Cloudflare Access only accepts the email we approved. A different inbox will be denied even if the Jellyfin password is correct.

  3. Prefer desktop first

    Complete browser login on a computer once. Then set up WARP on your phone if you need mobile access.

    Tip: Bookmark jellyfin.nebulaservices.live after it loads successfully.

Method A — Browser (desktop / laptop)

Fastest path. Works in Chrome, Edge, Firefox, or Safari.

  1. Open the library URL

    Go to https://jellyfin.nebulaservices.live. Use HTTPS only.

  2. Complete Cloudflare Access

    Sign in with the exact email from your approval letter. Enter the one-time code Cloudflare sends to that inbox.

    Stuck here? Wrong email is the most common issue. It must match the approval letter character for character.
  3. Sign in to Jellyfin

    Enter the username and password from the approval email. If approval was only a few minutes ago and login fails, wait 5–10 minutes and try again.

  4. Play media

    Prefer Direct Play when available. If buffering, lower quality in the player. Report broken titles via Support — never post credentials publicly.

Method B — Mobile & Cloudflare One (WARP)

Use this on phones or networks that block the library. Keep WARP connected while streaming.

  1. Install official WARP

    Install Cloudflare WARP / Cloudflare One from the App Store, Google Play, or Cloudflare’s official desktop download only.

  2. Join the organization

    In WARP, choose organization / team login and enter exactly:

    nebulaservices

  3. Authenticate

    Sign in with the same approved email. Toggle the connection On and leave it on while you stream.

  4. Open Jellyfin

    With WARP connected, open https://jellyfin.nebulaservices.live, complete Access, then sign in with your library credentials.

    In the Jellyfin app, add that same server URL as a custom server.

  5. If it still fails
    • Confirm WARP shows connected to nebulaservices
    • Confirm Access used the approved email
    • Confirm password matches the approval letter
    • Open Support with device type and which step fails

Need help?

Use the Support Center for account and technical issues.

  1. Support Center

    nebulaservices.live/support.html — FAQs and a general support form (not the media access application).

  2. Do not share credentials

    Sharing accounts or access is grounds for termination. See Legal.
