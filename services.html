Services

What you get
after approval.

A private media stack: Jellyfin for playback, Cloudflare Access for identity, and optional Cloudflare One for mobile and locked networks.

✧

Private media library

Stream from a curated Jellyfin library in the browser or supported apps. Free accounts can browse and watch existing titles. Donor tiers add monthly show and movie request quotas that we fulfill into the library.

◈

Cloudflare Access

Every session hits an identity check at the edge. Only emails we have explicitly allowed can pass. Your approval letter lists the address to use; other identities will be denied.

◎

Cloudflare One (WARP)

Optional on desktop; recommended on mobile. Connect to organization nebulaservices so traffic to the library follows our Zero Trust path. Setup steps are on the public Instructions page.

▣

Packages

Free — view-only. Donor ($10) — 1 show + 3 movies/month. Super ($15) — 3 shows + 10 movies. Mega ($20) — 5 shows + 20 movies. Queue times depend on volume.

Boundaries

Media access only.

The request form is for library access. It does not grant infrastructure control or admin rights. After approval, follow the public Instructions page for setup and status.
